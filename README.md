# Christmas Tree

Interactive 3D Christmas Tree built with Three.js.

## Features

- Realistic pine needle rendering with layered textures
- Falling snow particles
- Twinkling tree lights and ornaments
- Fireworks effects
- Tree explosion animation
- Photo upload to decorate the tree
- Auto-rotation with orbit controls

## Requirements

- Node.js 16+

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Open your browser to `http://localhost:5173`

## Build for Production

```bash
npm run build
```

The built files will be in the `dist` folder.

To preview the production build:
```bash
npm run preview
```

## Controls

- **Mouse drag**: Rotate camera around the tree
- **Scroll**: Zoom in/out
- **Upload Photos**: Add photos as ornaments on the tree
- **Fireworks**: Trigger firework effects
- **Tree Explosion**: Explode and reassemble the tree
- **Toggle Rotation**: Start/stop auto-rotation
